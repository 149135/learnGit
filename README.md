# 于宪森待办记录

一个轻量的个人待办清单，由单个 HTML 文件实现，无需安装任何依赖。

## 文件说明

| 文件 | 说明 |
| --- | --- |
| `index.html` | 待办清单页面，支持添加、勾选完成、删除与「清除已完成」，数据持久化在本机浏览器的 `localStorage` 中 |
| `README.md` | 本说明文档 |

## 使用方法

1. 双击打开 `index.html`（默认浏览器即可）。
2. 在输入框中填写事项，回车或点击「添加」。
3. 点击事项左侧方块标记完成；点击「删除」移除事项；底部「清除已完成」可一键清理。
4. 数据存储在浏览器 `localStorage`（键名 `yuxiansen-todos`），关闭页面后会自动保留。

> 提示：数据存在浏览器本地，与浏览器及访问地址绑定；清除浏览器缓存或换用无痕模式会导致记录丢失。

## 数据存储位置

- 存储键：`yuxiansen-todos`
- 存储格式：JSON 数组，每个元素为 `{ "text": "事项内容", "done": false }`
